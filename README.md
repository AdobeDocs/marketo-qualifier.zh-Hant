# 協助撰寫說明檔案

我們歡迎社群成員和Adobe員工出力貢獻。

## Adobe開放原始碼行為準則

此專案遵循[Adobe Open Source行為準則](code-of-conduct.md)或
[.NET Foundation行為準則](https://dotnetfoundation.org/code-of-conduct)。
如需詳細資訊，請參閱[參與](contributing.md)。

## 如何貢獻 Adobe 內容

如果您不是Adobe員工，您可以提交社群貢獻。 檔案團隊會檢閱公開存放庫中的貢獻內容，並與Adobe的內部系統同步已核准的變更。

如果您是Adobe員工，請直接貢獻給私人[Adobe GitHub存放庫](https://git.corp.adobe.com/AdobeDocs/)。 如需詳細資訊，請參閱適用於Adobe員工的Adobe Experience League撰寫指南。

## 外部貢獻者

### 微幅變更

如果您想要貢獻微幅更新：

1. 移至您要編輯的主題。
1. 在&#x200B;**中，此內容是否有所幫助？** 在頁面底部的橫幅，選取&#x200B;**詳細的意見選項**。
1. 選取&#x200B;**建議編輯**&#x200B;並提交包含您變更的提取請求(PR)。

   如需詳細資訊，請參閱[Adobe檔案投稿人指南](https://experienceleague.adobe.com/zh-hant/docs/contributor/contributor-guide/introduction)。

您為此存放庫文件和程式碼範例提交的微幅更正或釐清，均屬於 Adobe 使用條款規範的範圍。

### 重大變更和新主題

若要建立主題或提出重大變更，請從適當的Git存放庫中的&#x200B;**問題**&#x200B;索引標籤提交問題。 檔案團隊成員與您合作以商定計畫並發佈修訂版本。

>[!NOTE]
>
>如果您提交重大檔案或程式碼變更，提取請求會提示您完成線上貢獻者授權合約(CLA)。 在檔案團隊檢閱您的提取請求之前，請先完成CLA。

### 工具

使用GitHub介面進行基本編輯。 若為主要貢獻專案，請建立存放庫復本。

如需詳細資訊，請參閱[Adobe檔案投稿人指南](https://experienceleague.adobe.com/zh-hant/docs/contributor/contributor-guide/introduction)。

## 內部貢獻者

若您是Adobe技術撰寫人員、專案經理或產品開發人員，且撰寫技術文章，請使用[私人存放庫](https://git.corp.adobe.com/AdobeDocs)。

## 為您的主題設定格式

此存放庫中的文章使用GitHub Flavored Markdown。 如需說明，請參閱：

* [Markdown 基本介紹](https://help.github.com/articles/getting-started-with-writing-and-formatting-on-github/)
* [可列印的Markdown速查表](https://guides.github.com/pdfs/markdown-cheatsheet-online.pdf)

## 標籤

公用存放庫會自動指派標籤給提取請求：

* **變更已傳送給作者**：作者已收到處理提取要求的通知。
* **準備合併**：提取要求已準備好檢閱。
